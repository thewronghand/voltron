# r5: 3차 리뷰 지적 반영

r4 이후 호출 세션은 코드를 고치지 않았다. 실곡에서 MR·ASS는 브랜치 이전과 바이트 동일, MP4는 연속 두 번 렌더가 바이트 동일함을 확인했다.

## 1. 외부 MP3 길이 (video.py)
- 문제: `_audio_duration`이 `AudioFile.frames`를 그대로 쓴다. Xing/Info 헤더가 없는 CBR MP3는 `frames`가 추정값이다(pedalboard `exact_duration_known == False`). `thebooth video --audio 외부.mp3`에서 영상이 오디오보다 길거나 짧아질 수 있다.
- 정책: `exact_duration_known`이 False이면 파일을 끝까지 읽어 실제 프레임 수를 센다(청크 단위로 읽어 메모리를 아낀다). 속성이 없는 형식이면 지금처럼 `frames`를 쓴다.
- 테스트: 헤더 없는 MP3에서 길이가 실제 디코딩 길이와 맞는지. 테스트 파일은 직접 만든 사인파를 쓰고, 만들기 어렵다면 `exact_duration_known`을 monkeypatch한 가짜로 분기를 확인한다.

## 2. 공용 문구에서 옵션 이름 제거 (pipeline.py)
- `"영상에는 --lyrics 가사 파일이 필요합니다."` → `"영상에는 가사 파일이 필요합니다."`
- `"--vocals 경로가 원곡 또는 MR 출력과 같습니다: …"` → `"보컬 출력 경로가 원곡 또는 MR 출력과 같습니다: …"`
- `validate_make`·`_check_paths`가 내는 다른 문구에도 `--옵션` 표기가 남아 있으면 같은 방식으로 바꾼다. CLI 전용 "참고:" 안내는 CLI 문구라 그대로 둔다.
- 테스트: 사전 검사 오류 메시지(서버 400 응답 포함)에 `--`로 시작하는 옵션 표기가 없는지.

## 3. 입력값 40자 자르기 누락
- `지원하지 않는 언어 코드: {language}`, `manifest에 없는 모델: {model_id}`도 `option_value()`로 감싼다.
- 테스트: 긴 값이 잘리는지. 기존 `… 언어 코드: jp` 기대는 유지한다.

## 4. 작은 정리
- `models pull` 진행 표시 형식을 이전처럼 `12.3MB/45.6MB`로 되돌린다(현재 `12.3/45.6MB`).
- `tools.check_ass` 명령에도 `-nostdin`을 넣는다.
- 렌더 단계에서 `stage("render")`가 두 번 불리지 않게 한 곳으로 줄인다.
- README "앱과의 계약"에 두 가지를 적는다.
  - 앱은 사이드카 stdin을 반드시 `pipe`로 띄운다. `ignore`(/dev/null)면 즉시 EOF로 종료된다.
  - SSE 순서 규칙: 첫 이벤트는 id 없는 현재 스냅샷이고, 이어서 `Last-Event-ID` 이후의 기록이 재생된다. 화면은 스냅샷을 초기값으로 쓰고, 이후 이벤트는 순번이 더 큰 것만 적용한다.
- `jobs.events_after`: 없는 작업 id면 KeyError 대신 빈 목록을 돌려준다.
