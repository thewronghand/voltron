# Tactics Crawler

TFT식 자동전투(오토배틀러) + 덱빌딩 로그라이크 던전크롤러. Slay the Spire식 맵 진행 위에 TFT식 보드 전투를 얹는다. **Godot 4 / GDScript** 기반.

> 이 파일은 `tactics-crawler/` 하위(코드 레포 포함)에 공통 적용된다.
> 공통 원칙(`voltron-personal/CLAUDE.md`) + 전역 규칙(`~/.claude/CLAUDE.md`)도 자동 상속됨.
> **현재 단계: 기획(GDD) 우선. 코드 레포(`tactics-crawler-code/`)는 기획이 충분히 무르익은 뒤 생성한다.**

---

## 정체성

- **장르**: 오토배틀러(TFT) × 덱빌딩 로그라이크(Slay the Spire) × 던전크롤러
- **엔진**: Godot 4 (GDScript). 2D 헥스 그리드 보드.
- **목적**: 의현 개인 게임 프로젝트. 1차 목표는 "전투 1판이 굴러가는 프로토타입".
- **git**: 개인 계정 `thewronghand` (코드 레포 생성 시 설정).
- **이름**: `tactics-crawler`는 가칭. 스토리·브랜딩 확정 시 변경 가능.

## 핵심 디자인 결정 (확정)

| 축 | 결정 |
|----|------|
| 전투 | TFT식 자동전투. 보드에 유닛 배치 후 자동 진행. 플레이어 개입은 배치·아이템뿐. |
| 진행 | Slay the Spire식 맵. 경로 선택 → 노드(전투/이벤트/상점/보스). 층마다 중간보스+층 보스. |
| 핵심 재미 | **시너지** (종족/직업 N명 → 패시브). 1순위. |
| 합체 | TFT식 별 등급. 같은 유닛 3개 → ★2 합체. |
| 보드 | TFT급 (4×7 헥스 규모). 유닛 8~10기, 시너지 다중 발동. |
| 지형 | **절차적 지형 — 전략에 개입하되 단순 로직만.** 장애물 칸, 도발 허수아비 등 정적 오브젝트. 복잡한 동적 길찾기는 피한다. |

### 성장 보상 3채널

| 보상 | 획득처 | 역할 |
|------|--------|------|
| 렐릭 (= TFT 증강체) | 이벤트 노드, 중간보스/보스 | 판을 관통하는 구조적 버프 |
| 랜덤 유닛 | 일반 전투 승리(상점 1회 이용권), **상점 노드(리롤)** | 보드 채우기·합체·시너지 완성 |
| 조합 아이템 | 보물 전투 승리, 상점 노드 구매 | 특정 유닛 강화 |

### 노드 종류

일반 전투 / 보물 전투(아이템) / 이벤트(렐릭·분기) / 상점(리롤 유닛 + 아이템 구매) / 중간보스 / 보스

## 작업 하네스

- **기획 우선**: 코드보다 GDD(`design/`)를 먼저 채운다. 시스템·시너지·밸런스 골격을 글로 확정한 뒤 구현.
- **세션 연결**: 작업 내용 확정 시 `/voltron-bus`로 personal 버스 연결 **제안** (연결명 `tc-작업명`, 티켓 없음). 접두사는 `tc`. ※ 상위 CLAUDE.md의 접두사 목록에 `tc` 추가 필요.
- **큰 작업**: `/ralph` — 태스크 분해(승인) → 메인 구현 → `reviewer` 독립 리뷰.
- **지식 축적**:
  - 같은 실수 반복 → `tactics-crawler-workflow/lessons/` ("증상 → 원인 → 교훈")
  - 복잡한 설계 결정 → `tactics-crawler-workflow/why-tho/`
  - 반복 패턴·체크리스트 → `tactics-crawler-workflow/cookbook/`
  - 하네스는 실패에서 자란다 (메타 원칙: `voltron-personal/bootstrap/`)
